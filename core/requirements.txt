# Core deps — the shared layer, so every leaf inherits these.
#   - models.py: pydantic schemas + the Job carrier.
#   - fetch.py:  httpx + JSON-LD parsing + a reader-API fallback (no heavy scraper stack).
#   - index.py:  langchain-core for the `Document` type and the numpy-backed InMemoryVectorStore,
#                fastembed for the embedder. fastembed serves the same bge-small-en-v1.5 weights as
#                sentence-transformers via ONNX, with no torch: ~30 MB of wheels and 64 MB of
#                weights, against 1.0 GB — and on Linux torch declares the whole CUDA stack, which a
#                CPU-only tool would download and never execute. Document building stays pure, so
#                the model is fetched on first embed and never at import.
